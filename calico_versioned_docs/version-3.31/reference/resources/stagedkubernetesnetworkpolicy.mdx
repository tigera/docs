# Staged Kubernetes network policy

A staged Kubernetes network policy resource (`StagedKubernetesNetworkPolicy`) represents a staged version
of [Kubernetes network policy](https://kubernetes.io/docs/concepts/services-networking/network-policies).
This is used to preview network behavior before actually enforcing the network policy. Once persisted, this
will create a Kubernetes network policy backed by a $[prodname]
[network policy](networkpolicy.mdx).

For `kubectl` [commands](https://kubernetes.io/docs/reference/kubectl/overview/), the following case-insensitive aliases
may be used to specify the resource type on the CLI:
`stagedkubernetesnetworkpolicy.projectcalico.org`, `stagedkubernetesnetworkpolicies.projectcalico.org` and abbreviations such as
`stagedkubernetesnetworkpolicy.p` and `stagedkubernetesnetworkpolicies.p`.

## Sample YAML

Below is a sample policy created from the example policy from the
[Kubernetes NetworkPolicy documentation](https://kubernetes.io/docs/concepts/services-networking/network-policies/#networkpolicy-resource).
The only difference between this policy and the example Kubernetes version is that the `apiVersion` and `kind` are changed
to properly specify a staged Kubernetes network policy.

```yaml
apiVersion: projectcalico.org/v3
kind: StagedKubernetesNetworkPolicy
metadata:
  name: test-network-policy
  namespace: default
spec:
  podSelector:
    matchLabels:
      role: db
  policyTypes:
    - Ingress
    - Egress
  ingress:
    - from:
        - ipBlock:
            cidr: 172.17.0.0/16
            except:
              - 172.17.1.0/24
        - namespaceSelector:
            matchLabels:
              project: myproject
        - podSelector:
            matchLabels:
              role: frontend
      ports:
        - protocol: TCP
          port: 6379
  egress:
    - to:
        - ipBlock:
            cidr: 10.0.0.0/24
      ports:
        - protocol: TCP
          port: 5978
```

## Definition

### Metadata

| Field     | Description                                                        | Accepted Values                                     | Schema | Default   |
| --------- | ------------------------------------------------------------------ | --------------------------------------------------- | ------ | --------- |
| name      | The name of the staged Kubernetes network policy. Required.        | Alphanumeric string with optional `.`, `_`, or `-`. | string |           |
| namespace | Namespace provides an additional qualification to a resource name. |                                                     | string | "default" |

### Spec

| Field        | Description                                                                                                                                                                                                  | Accepted Values                    | Schema                                                                                                                                        | Default                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| stagedAction | Change that the staged policy previews. `Set` previews creating or updating the Kubernetes network policy with the same name. `Delete` previews deleting it, and requires all other spec fields to be empty. | `Set`, `Delete`, `Learn`, `Ignore` | string                                                                                                                                        | `Set`                               |
| podSelector  | Selects the pods in the policy's namespace to which this policy applies. An empty selector selects all pods in the namespace.                                                                                |                                    | [LabelSelector](https://kubernetes.io/docs/reference/kubernetes-api/common-definitions/label-selector/)                                       |                                     |
| ingress      | List of ingress rules applied to the selected pods. If the policy applies to ingress traffic and this list is empty, the policy allows no ingress traffic.                                                   |                                    | List of [NetworkPolicyIngressRule](https://kubernetes.io/docs/reference/kubernetes-api/policy-resources/network-policy-v1/#NetworkPolicySpec) |                                     |
| egress       | List of egress rules applied to the selected pods. If the policy applies to egress traffic and this list is empty, the policy allows no egress traffic.                                                      |                                    | List of [NetworkPolicyEgressRule](https://kubernetes.io/docs/reference/kubernetes-api/policy-resources/network-policy-v1/#NetworkPolicySpec)  |                                     |
| policyTypes  | Traffic directions the policy applies to. If not set, the policy applies to `Ingress`, and also to `Egress` if it has egress rules. To write an egress-only policy, set this to `Egress`.                    | `Ingress`, `Egress`                | List of strings                                                                                                                               | Depends on presence of egress rules |

The ingress and egress rules use the same schema as Kubernetes `NetworkPolicy`.
For the rule fields, see the [Kubernetes NetworkPolicy API reference](https://kubernetes.io/docs/reference/kubernetes-api/policy-resources/network-policy-v1/).
