# Profile

A profile resource (Profile) represents a group of endpoints that inherit a shared set of labels.
For historic reasons, profiles can also include
policy rules, but that feature is deprecated in favor of the much more
flexible [NetworkPolicy](networkpolicy.mdx) and
[GlobalNetworkPolicy](globalnetworkpolicy.mdx) resources.
Profile is a cluster-scoped resource.

Each $[prodname] endpoint or host endpoint can be assigned to zero or more profiles.

With the Kubernetes datastore, profiles are read-only. $[prodname] generates a profile for each namespace and service account, and you cannot create, update, or delete profiles.

For `kubectl` commands, you can use the aliases `profile.projectcalico.org`, `profiles.projectcalico.org`, `profile.p`, and `profiles.p`.

## Sample YAML

The following sample profile applies the label `stage: development` to any endpoint that includes `dev-apps` in its list of profiles.

```yaml
apiVersion: projectcalico.org/v3
kind: Profile
metadata:
  name: dev-apps
spec:
  labelsToApply:
    stage: development
```

## Definition

### Metadata

| Field    | Description                           | Accepted Values                                                                                                          | Schema                  | Default |
| -------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------- | ------- |
| `name`   | The name of this profile. Required.   | Lowercase alphanumeric characters, `-`, or `.`. Must start and end with an alphanumeric character. Up to 253 characters. | string                  |         |
| `labels` | A set of labels for this profile.     |                                                                                                                          | map of string to string |         |

### Spec

| Field                          | Description                                                                                                    | Accepted Values | Schema                                 | Default |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- | --------------- | -------------------------------------- | ------- |
| `ingress` _(deprecated)_       | The ingress rules belonging to this profile.                                                                   |                 | list of [Rule](networkpolicy.mdx#rule) |         |
| `egress` _(deprecated)_        | The egress rules belonging to this profile.                                                                    |                 | list of [Rule](networkpolicy.mdx#rule) |         |
| `labelsToApply`                | An optional set of labels to apply to each endpoint in this profile (in addition to the endpoint's own labels) |                 | map of string to string                |         |

For `Rule` details please see the [NetworkPolicy](networkpolicy.mdx) or
[GlobalNetworkPolicy](globalnetworkpolicy.mdx) resource.
