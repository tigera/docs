If you use Calico Ingress Gateway, this release bumps the bundled Envoy Gateway to v1.9.1, which takes the bundled Gateway API CRDs from v1.5.1 to v1.6.1. Gateway API v1.6 removes `sessionPersistence.idleTimeout` from `HTTPRoute`, and Envoy Gateway v1.9 rejects an empty `clientIPDetection` in `ClientTrafficPolicy`. A manifest that uses either is rejected once the CRDs are upgraded.

Before you upgrade, remove `sessionPersistence.idleTimeout` from any `HTTPRoute`, and any empty `clientIPDetection` from any `ClientTrafficPolicy`.
