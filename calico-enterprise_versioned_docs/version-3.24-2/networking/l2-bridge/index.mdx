# L2 bridge networking

:::note

L2 bridge networking is a tech preview feature.
APIs and behavior may change before GA.

:::

Attach KubeVirt VMs and pods to a VLAN your physical network already carries, so they share a broadcast domain with the servers already on it and keep the addresses they arrive with.

Setup follows one of two paths, and your nodes decide which.
If the interface carrying your VLANs is separate from the one holding the node's own IP address, $[prodname] builds the bridge for you: go straight to [Connect workloads to an existing VLAN](connect-vlan.mdx).
If your only uplink carries both, you build the bridge and $[prodname] uses it: start with [Prepare a bridge on single-uplink nodes](byo-bridge.mdx), then come back for the rest.

[About L2 bridge networking](about-l2-bridge.mdx) explains the model, both bridge modes, and where policy is enforced.
