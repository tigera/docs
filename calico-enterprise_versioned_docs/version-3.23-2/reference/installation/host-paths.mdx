# Host paths used by Calico Enterprise components

Several $[prodname] components mount directories or files from the host node.
If an admission policy, such as Kyverno or OPA Gatekeeper, limits the host paths that pods can use, it must allow these paths, or the components fail to start.

Use this page to build or check your allow-list before you install or upgrade.
Each table lists the host paths for one component:

- **Volume** is the volume name in the pod spec.
- **Access** is read-only or read-write. "Not mounted" means the volume is declared in the pod spec but no container mounts it. Policies that inspect pod volumes still see it.
- **When present** says whether the path is always there or depends on your configuration.
- **Added in** shows the 3.23 patch release that added the path. It is blank for paths that were present in 3.23.0.

## Default CNI and FlexVolume directories

The operator sets these directories when the Installation resource does not.
You can set the CNI directories with `cni.binDir` and `cni.confDir`, the Windows CNI directories with `windowsNodes`, and the FlexVolume directory with `flexVolumePath`.
For details, see the [Installation resource reference](api.mdx#installationspec).

| Platform | CNI binary directory | CNI configuration directory | FlexVolume directory |
| --- | --- | --- | --- |
| OpenShift | `/var/lib/cni/bin` | `/var/run/multus/cni/net.d` | `/etc/kubernetes/kubelet-plugins/volume/exec/` |
| GKE | `/home/kubernetes/bin` | `/etc/cni/net.d` | `/home/kubernetes/flexvolume/` |
| AKS | `/opt/cni/bin` | `/etc/cni/net.d` | `/etc/kubernetes/volumeplugins/` |
| RKE2 | `/opt/cni/bin` | `/etc/cni/net.d` | `/var/lib/kubelet/volumeplugins/` |
| All others | `/opt/cni/bin` | `/etc/cni/net.d` | `/usr/libexec/kubernetes/kubelet-plugins/volume/exec/` |

On Windows nodes, the CNI binary and configuration directories default to `/k/azurecni/bin` and `/k/azurecni/netconf` on AKS, `/Program Files/Amazon/EKS/cni` and `/Program Files/Amazon/EKS/cni/config` on EKS, and `/opt/cni/bin` and `/etc/cni/net.d` elsewhere.
The Windows CNI log directory is `/var/log/calico/cni`.
