# Upgrade Calico Cloud

How you upgrade a managed cluster depends on how you connected it to $[prodname].
If you connected the cluster from the web console, upgrade it from the web console.
If you connected it as part of an automated workflow, upgrade it with Helm.

## Upgrade a cluster from the web console

To upgrade a managed cluster to the latest version of $[prodname]:

1. From the web console, go to the **Managed Clusters** page.
1. If your organization uses multiple projects to group managed clusters, click the **Project** menu and select the project you want your cluster to be part of.
1. For the cluster you want to upgrade, select **Actions** > **Reinstall**.
1. In the **Reinstall Cluster** dialog, select a newer version of $[prodname] from the list, click **Reinstall**, and copy the generated command.
   The dialog generates either a kubectl or a Helm command, to match the way the cluster was connected to $[prodname].
1. From a terminal, paste and run the command.
   The cluster's status under **Connection Status** changes to **Disconnected: Installing**.
   When the upgrade is complete, the status changes to **Connected**.

## Upgrade a cluster as part of an automated workflow

If you connected the cluster using client credentials and your own `values.yaml` file, upgrade it by running `helm upgrade` with a newer version, rather than from the web console.
For the procedure, see [Upgrade Calico Cloud as part of an automated workflow](install-automated.mdx#upgrade-calico-cloud-as-part-of-an-automated-workflow).
