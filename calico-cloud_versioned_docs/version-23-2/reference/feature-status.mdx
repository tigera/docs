# Feature status

$[prodname] is built on Calico Enterprise, so a feature's technology-preview and deprecation status in $[prodname] follows the Calico Enterprise release it's built on.
The tables below show that status as of $[prodname]'s current release.

For the release notes each status change came from, see [Release notes](../release-notes/index.mdx).

## Technology preview features

Technology preview features are for evaluation and feedback only and are **not supported for production use**. Behavior, APIs, and configuration may change before a feature reaches general availability.

## Deprecated and removed features

Deprecated features are still present and supported, but they are scheduled for removal. You should consider migrating away from a deprecated feature before it is removed.
