:::note

`calico-v3-crds.yaml` declares its `MutatingAdmissionPolicy` resources at `admissionregistration.k8s.io/v1`, which Kubernetes serves from 1.36 onwards. On Kubernetes 1.34 and 1.35, use `calico-v3-crds-v1beta1.yaml` instead, which declares the same resources at `admissionregistration.k8s.io/v1beta1`.

:::
