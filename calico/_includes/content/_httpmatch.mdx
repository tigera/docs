An HTTPMatch matches attributes of an HTTP request.

Example:

```yaml
http:
  methods: ['GET', 'PUT']
  paths:
    - exact: '/projects/calico'
    - prefix: '/users'
```

| Field   | Description                                                                                                                      | Schema                                  |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| methods | Match HTTP methods. Case sensitive. [Standard HTTP method descriptions.](https://www.w3.org/Protocols/rfc2616/rfc2616-sec9.html) | list of strings                         |
| paths   | Match HTTP paths. Case sensitive.                                                                                                | list of [HTTPPathMatch](#httppathmatch) |

### HTTPPathMatch

| Syntax | Example             | Description                                                                     |
| ------ | ------------------- | ------------------------------------------------------------------------------- |
| exact  | `exact: "/foo/bar"` | Matches the exact path after normalization, not including the query string or fragments. For example, normalization decodes percent-escapes, collapses repeated slashes, and resolves `.` and `..` segments. |
| prefix | `prefix: "/keys"`   | Matches the given path and any path below it, at a path-segment boundary. For example, `/keys` matches `/keys/1` but not `/keystore`.                             |
