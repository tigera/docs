:::note

`v3_projectcalico_org.yaml` declares its `MutatingAdmissionPolicy` resources at `admissionregistration.k8s.io/v1`, which Kubernetes serves from 1.36 onwards. On Kubernetes 1.34 and 1.35, apply `v3_projectcalico_org-v1beta1.yaml` instead, which declares the same resources at `admissionregistration.k8s.io/v1beta1`. Helm installs and operator-managed CRDs detect the version the cluster serves, so they do not need this choice.

:::
